# 스마트스토어·롯데ON Astryx 시안

스마트스토어의 1~5 단계와 사진 색상·구도 수정, 롯데ON의 1~3 단계와 공식 자료 검토를 보여 주는 독립적인 화면 시안입니다. 실제 Astryx 0.7.16의 Theme, Button, TextInput, Badge와 React 19를 사용합니다.

```powershell
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

시작 후 `.runtime/session.json`의 port와 key로 `http://127.0.0.1:<port>/?key=<key>`에 접속합니다. 실행 링크와 세션 파일은 공유하지 않습니다.

롯데ON 시안은 같은 서버의 `/lotteon?key=<key>`로 접속합니다. 스마트스토어 시안 서버를 유지한 채 별도로 실행하려면 아래처럼 실행합니다. 새 서버의 접속 정보는 `.runtime/lotte-session.json`에 저장되며 기존 세션을 덮어쓰지 않습니다.

```powershell
$env:ASTRYX_PREVIEW_CHANNEL = 'lotteon'
pnpm start
```

- 프로젝트 루트의 `server.mjs`, `public/app.js`, 실제 롯데ON·스마트스토어 화면과 실행 서버는 수정하지 않습니다.
- 저장된 상품 자료를 읽어서 표시하고, 사진은 로컬 데이터 폴더에서만 제공합니다. 사진과 상품별 자료는 이 폴더나 GitHub에 복사하지 않습니다.
- 품번 검색은 이미 저장된 상품만 불러옵니다. 공식몰 재수집, 판매자 로그인, 업로드 API를 호출하지 않습니다.
- 사진 색상·구도 변경, 순서 이동, 대표 선택, 단계 확인은 브라우저 메모리의 시안 상태에만 적용합니다.
- 롯데ON은 판매자 화면 준비 → 상품 수집·검토 → 입력 시작 순서입니다. 검토 영역에는 기본정보, 사진·상세, 옵션·분류를 나눠 표시합니다.
- 롯데ON 대표·추가사진 최대 2장과 상세·사이즈·체크업·정보고시는 저장된 개별 원본을 표시합니다. 배경 작업과 1500×1500 배치 창은 구성 미리보기이며 실제 이미지 생성·변환·교체는 하지 않습니다.
- 롯데ON 기본정보 수정, 추가사진 포함·제외, 옵션 선택, 분류 수정은 브라우저 상태에만 반영합니다. 옵션 재고의 초기 10은 입력값 예시이며 실제 판매 재고가 아닙니다. 공통분류와 채널분류는 각각 저장된 경로를 표시합니다.
- 롯데ON 3번의 진행 화면은 시작·중지·경과 시간·완료를 체험하는 10초 시뮬레이션입니다. 판매처 연결·입력·임시저장·최종등록을 실행하지 않습니다.
- 5번은 진행 화면 체험입니다. 실제 상품 입력·저장·등록과 연결하지 않았습니다.
- 구도 근거가 없는 사진의 초기 구도는 `확인 필요`로 유지합니다.
- 저장된 대표사진만 초기 대표로 표시합니다. 대표가 없는 자료에서 첫 사진을 자동 지정하지 않습니다.
- 사진 체크는 대표 선택과 독립적이며 Shift 범위 선택을 지원합니다. 체크한 사진의 색상을 바꿔도 위치를 유지하고, `색상별 정렬` 또는 `시안에 반영` 때 묶습니다. 직접 정한 구도는 순서를 바꿔도 유지합니다.
- 실제 상품등록 기능으로의 전환은 별도 작업입니다.

검증: 빌드, 실제 저장 사진 표시, 대표 선택, 같은 색상 드래그와 순서 이동, 색상 변경 중 위치 유지, 직접 선택한 구도 보존, 취소, 저장된 품번 검색, 1~5단계 이동, 진행 체험 시작·중지·완료를 확인했습니다. 390·430·768·1152px에서 페이지와 사진 수정 창의 가로 넘침이 없고, 판매처 쓰기 요청이 발생하지 않는 것을 확인했습니다. 실제 상품 수집·판매처 입력·업로드의 검증은 포함하지 않습니다.

롯데ON 검증: 376501의 저장된 원본 7장 표시, 기본정보·키워드 수정, 추가사진 포함·제외, 원본 확대와 배경 작업 창, 색상·사이즈 조합, 입력 재고 편집, 공통·채널분류 분리, 검토 완료, 진행 체험의 시작·중지·닫기·재열기·완료를 확인했습니다. 없는 품번을 검색해도 이전 상품이 유지되며 다시 불러오면 저장된 원본 값으로 돌아갑니다. 390·430·768·1152px에서 세 검토 탭과 대화상자의 가로 넘침이 없고, 원본 product.json 해시가 같으며 쓰기 요청·브라우저 오류가 없었습니다. 스마트스토어 시안의 기존 점검도 다시 통과했습니다.
