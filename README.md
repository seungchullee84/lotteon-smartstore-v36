# 상품등록기

롯데ON·스마트스토어 상품등록 도우미입니다. 소스 파일 변경을 감지해 버전과 한국 시간 기준 최종 수정일(요일 포함)을 자동 갱신합니다. 실행 중에는 약 2초 간격으로 확인하며, 종료 중 수정한 내용은 다음 실행 시 반영합니다. 상품 데이터·로그·브라우저 프로필은 버전 계산에서 제외합니다.

## 실행

Windows, Node.js 20.19 이상 및 구글 크롬(Google Chrome)이 필요합니다.

```sh
npm install
npm run setup
npm start
```

Windows에서는 `start.cmd`로도 실행할 수 있습니다. 판매자 계정은 실행 후 열리는 전용 크롬 창에서 직접 로그인하세요. 실제 상품 등록 전 수집 정보와 입력 내용을 확인하세요.

## 배경 늘리기·합성

`배경 늘리기·합성` 버튼으로 원본 사진을 확인한 뒤, 등록기를 함께 열어 둔 현재 채팅에 `합성해줘`라고 보내세요. 채팅에서 내장 이미지 생성 도구로 합성하고 대표이미지에 적용합니다. 버튼은 안내를 표시하며 채팅 메시지를 자동 전송하지 않습니다. API 키 입력은 필요하지 않습니다.

완성된 결과는 현재 수집한 상품 폴더에 1500×1500 JPEG로 저장되며 대표이미지 미리보기·저장·업로드에 자동 적용됩니다. 실패하거나 중단하면 기존 대표이미지를 유지합니다. 상품을 외부 판매처에 저장하거나 등록하는 동작은 별도입니다.

## 공개 범위

프로그램 소스, 화면, 테스트, 분류표 및 OCR 언어 파일을 포함합니다.
로그인 브라우저 프로필, 세션 토큰, 비밀번호 설정, 상품별 작업 기록, 로그 및 개인 Codex 채팅 연결은 포함하지 않습니다.

기존 비공개 저장소와 실행 중인 로컬 앱은 그대로 유지됩니다.

## GitHub 자동 반영

프로그램이 실행 중이면 저장된 소스 파일의 변경을 확인하고, 수정이 잠시 멈춘 뒤 약 10~20초 내 자동 커밋하여 연결된 GitHub main 브랜치에 업로드합니다. 화면 상단에서 반영 상태를 확인할 수 있습니다. 종료 중 수정한 파일은 다음 실행 시 반영합니다. Git 설치와 해당 저장소에 대한 Git 로그인 권한이 필요합니다.

로그인 프로필, 토큰, 환경변수 파일, 상품 사진·작업 기록과 data 폴더는 자동 업로드하지 않습니다. 인증 문자열로 보이는 내용이 발견되면 업로드를 중단합니다. 네트워크 오류는 다시 시도하며, 원격 변경과 충돌하면 덮어쓰지 않고 확인 메시지를 표시합니다.
