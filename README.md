# 상품등록기 v36

롯데ON·스마트스토어 상품등록 도우미의 2026-10-21 공개 소스 백업입니다.

## 실행

Windows, Node.js 20.19 이상 및 구글 크롬(Google Chrome)이 필요합니다.

```sh
npm install
npm run setup
npm start
```

Windows에서는 `start.cmd`로도 실행할 수 있습니다. 판매자 계정은 실행 후 열리는 전용 크롬 창에서 직접 로그인하세요. 실제 상품 등록 전 수집 정보와 입력 내용을 확인하세요.

## 공개 범위

프로그램 소스, 화면, 테스트, 분류표 및 OCR 언어 파일을 포함합니다.
로그인 브라우저 프로필, 세션 토큰, 비밀번호 설정, 상품별 작업 기록, 로그 및 개인 Codex 채팅 연결은 포함하지 않습니다.

기존 비공개 저장소와 실행 중인 로컬 앱은 그대로 유지됩니다.
